## 🧬 About Me

<img align="right" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" width="280" style="border-radius: 12px"/>

I'm **Ayush Singh** — a cybersecurity-focused developer who lives at the intersection of **breaking things** and **building them better**.

My world revolves around finding vulnerabilities before attackers do, understanding how systems fail, and then engineering them to be resilient. When I'm not in security mode, I'm writing automation scripts, spinning up backends, or diving deep into cloud infrastructure.

**What I'm actively levelling up in:**

🔍 &nbsp; Vulnerability Assessment & Penetration Testing (VAPT)  
🛡️ &nbsp; SOC fundamentals + incident response mindset  
☁️ &nbsp; AWS Cloud Security — VPC, IAM, Security Groups, EC2  
⚙️ &nbsp; Automation tools & scalable backend systems  
🧠 &nbsp; Threat intelligence & defensive security
